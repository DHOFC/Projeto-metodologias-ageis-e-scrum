# Metodologias Ágeis e Scrum no Desenvolvimento Web

Este repositório contém os artefatos do projeto acadêmico desenvolvido para o curso na área de Tecnologia da Informação do Centro Universitário Una[cite: 2]. O trabalho discute a contribuição das metodologias ágeis, com ênfase no framework Scrum, para o planejamento e o desenvolvimento de aplicações web.

## 📂 Arquivos e Artefatos do Projeto

Abaixo estão descritos os arquivos que compõem este repositório:

* **Artigo Acadêmico - Metodologias Ágeis e Scrum no Desenvolvimento Web (1).pdf**: Documento principal da pesquisa, que aborda os valores ágeis, os componentes do Scrum e apresenta um cenário hipotético de um portal de tarefas para demonstrar a aplicação prática do framework.
* **Diagrama de Classe.jpeg**: Representa a estrutura de classes do sistema de gestão conceitual, detalhando as relações entre entidades como `Usuario`, `Projeto`, `Sprint`, `Tarefa`, `ProductBacklog`, e as especializações de papéis como `ProductOwner`, `ScrumMaster` e `Desenvolvedor`.
* **Diagrama.jpeg**: Diagrama de casos de uso que mapeia as interações dos atores (Scrum Master, Product Owner e Equipe de Desenvolvimento) com as funcionalidades do sistema, tais como facilitar reuniões diárias, gerenciar o Product Backlog e fazer o planejamento da Sprint.
* **Fluxograma.jpeg**: Mapa mental que organiza visualmente os conceitos de Metodologias Ágeis e Scrum, ramificando os fundamentos do Manifesto Ágil, os pilares do empirismo (Transparência, Inspeção, Adaptação), valores, eventos e artefatos.
